Mechanism that permits cross-task resume
----------------------------------------
1. tools/queue_runtime.py sets active_checkpoint = YOLO_QUEUE_RESUME_CHECKPOINT or the script checkpoint.
2. train_dronevehicle_darkact_maalaf_postlaf_refine.py passes QUEUE.checkpoint to YOLO and records the run as PT-R012.
3. tools/pretrained_rerun_tracker.py verifies only that the model checkpoint equals the explicit resume path. It does not verify that the resume checkpoint belongs to PT-R012 or matches PT-R012's expected architecture/run.
4. /opt/yolo-monitor-agent/queue_agent.py discover_checkpoint() recursively scans the entire working directory for **/weights/last.pt and returns the one with the newest mtime. retry_or_finish() then stores that path as the current job's resume_checkpoint.

This global-newest-checkpoint fallback is the direct mechanism capable of attaching another experiment's last.pt to the current queue job.
