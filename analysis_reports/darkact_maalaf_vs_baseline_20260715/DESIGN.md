# Report design

- Audience: technical
- Delivery: portable self-contained HTML
- Reading path: answer first, metric impact, class-level driver, mechanism activation, paper-gap table, scope/method, limitations, next experiments, open questions
- Visual: one full-width single-series bar chart for class-level mAP50-95 delta; exact stage diagnostics and implementation differences use spacious tables
- Palette: single blue root with neutral text and grid; no red/green semantics
- Responsive behavior: full-width blocks, native portable reader, semantic table fallback
- Source strategy: all calculated claims resolve to `source_notes.md`; raw training/test/code/PDF sources are separately declared
